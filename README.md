# AI 에이전트 병목·해자 종목 데일리 리포트

매일 아침(월~토) 7시 무렵, **AI 에이전트 대중화로 병목이 생기고 해자를 가진 기업** 중에서
지금 매수 자리가 나온 종목을 골라 **진입가, 손절가, 피라미딩(추가매수) 가격**과 함께 텔레그램으로 보냅니다.

```
GitHub Actions (06:50 KST 시작)
  → 야후 파이낸스 시세 수집 (미국·한국 30종목 + QQQ·KODEX200)
  → 규칙 기반 분석: 시장 상태 → 추세 점수 → 매수 자리(셋업) → 가격 계산
  → (선택) Claude가 웹검색으로 최신 뉴스·해자 점검 코멘트 작성
  → 텔레그램 발송
```

## 1. 어떻게 종목을 고르나 (쉬운 설명)

### ① 유니버스: "병목 + 해자" 30종목 (`config.yaml`)
AI 에이전트는 질문 하나에 추론을 수십 번 반복하고, 긴 문맥을 기억하고, 여러 도구를 호출합니다.
그래서 수요가 공급보다 빨리 늘어나는 구간(병목)이 생깁니다.

| 병목 구간 | 종목 예 |
|---|---|
| 연산 | 엔비디아, 브로드컴, AMD |
| 제조·장비 | TSMC, ASML, 한미반도체 |
| 메모리 (HBM) | SK하이닉스, 삼성전자, 마이크론 |
| 네트워크·광 | 아리스타, 마벨, 크레도, 아스테라랩스, 루멘텀, 코히런트 |
| 전력·냉각 | 버티브, GE버노바, 이튼, 컨스텔레이션, HD현대일렉트릭, 효성중공업, LS ELECTRIC, 두산에너빌리티 |
| 플랫폼 | 마이크로소프트, 알파벳, 아마존 |
| 소프트웨어 | 팔란티어, 서비스나우, 크라우드스트라이크, 클라우드플레어 |

종목과 투자 아이디어(thesis)는 `config.yaml`에서 자유롭게 고칠 수 있습니다.
**이 목록은 "어떤 종목을 볼지"(성장주 가치투자 관점)이고, "언제 살지"는 아래 기술적 규칙이 정합니다.**

### ② 시장 상태 필터
- 미국은 QQQ, 한국은 KODEX200 ETF가 50일·200일 이동평균선 위에 있는지 확인
- 강세: 정상 / 중립: 1회 위험 75%로 축소 / 약세(200일선 아래): 50%로 축소

### ③ 추세 점수 (미너비니 트렌드 템플릿 8개 조건)
주가가 150·200일선 위, 200일선 상승 중, 52주 고점 근처, 상대강도(RS) 상위 등.
**8개 중 7개 이상 충족한 '상승추세' 종목만 추천**합니다.

### ④ 매수 자리(셋업) 판정
| 셋업 | 조건 | 진입 방법 |
|---|---|---|
| 돌파 직후 | 5거래일 이상 횡보한 뒤 20일 고점(피벗)을 오늘 돌파, 피벗+5% 이내 | 현재가 부근 매수 |
| 돌파 대기 | 피벗까지 5% 이내 | 피벗을 넘을 때 매수 (스톱 매수 주문) |
| 눌림목 | 상승추세 중 21일 지수이동평균선(EMA) 근처까지 조정 | 최근 거래일 고가를 넘을 때 매수 (반등 확인) |
| 과열 | 21일 EMA보다 3ATR 이상 위, 또는 50일선보다 25% 이상 위 | 추격 금지, 눌림 대기 |

### ⑤ 가격 계산 (모두 규칙대로 계산, AI는 가격을 만들지 않음)
- **손절가**: 최근 10일 최저가 바로 아래와 진입가−2ATR 중 진입가에 가까운 쪽.
  단, 1ATR보다 가까우면 1ATR로 둡니다. (ATR = 하루 평균 움직임 폭. 이보다 좁으면 일상적인 흔들림에 손절당함)
- **1R** = 진입가 − 손절가 (한 번 매매에서 감수하는 손실 단위)
- **피라미딩** (수익이 날 때만 추가매수)
  - 1차 50% @ 진입가
  - 2차 30% @ 진입가 + 1R → 전체 손절을 **진입가(본전)** 로 올림
  - 3차 20% @ 진입가 + 2R → 전체 손절을 **진입가 + 1R** 로 올림
  - 2차 이후 손절되면 손실은 처음 위험의 60% 미만, 3차 이후 손절되면 전체 손익이 플러스(+)
    (손절가에 갭 없이 체결된다는 가정)
- **목표**: 진입가 + 3R(손익비 3:1)에서 1/3 익절, 나머지는 '최근 고점 − 3ATR' 추적손절
- **비중**: 1차 매수분이 손절되면 계좌의 1%만 잃도록 계산 (`risk_per_trade_pct`), 1차 상한 25%
- 한국 종목은 KRX 호가단위에 맞춰 반올림

### ⑥ 추가 필터
- 실적발표 7일 이내면 −10점 + 경고 (발표 다음 날 갭이 생기면 손절가가 의미 없어짐)
- 같은 병목 구간(예: 메모리)에서는 1종목만 추천 → 같이 오르고 같이 빠지는 쏠림 방지

### ⑦ Claude 코멘트 루틴 (사용 중, API 요금 없음)
매일 07:07(월~토) Claude 루틴이 07:00 리포트가 저장한 추천 결과(`reports/latest.json`)를 읽고 추천 종목 뉴스를 웹검색으로 확인해
"한눈에 결론 / 뉴스(출처 번호) / 해자 / 강세·약세 근거 / 셋업과 뉴스 / Claude 의견"을 **🤖 Claude 코멘트** 메시지로 따로 보냅니다.
- 모델 Opus 5.5 + ultracode: 종목별 조사 에이전트 → 반박형 검증 에이전트(누락 악재 점검·실적일 확인) → 테마 에이전트, 최대 7개
- 출처 등급(공시·IR > 주요 언론 > 집계·의견 기사)을 두고, 의견(계획대로/신중/보류)은 정해진 조건으로만 바뀝니다
- API가 아니라 **Claude 구독 사용량**에서 차감됩니다 (사용량 확인: claude.ai/settings/usage)
- 루틴 관리(일시정지·수정·즉시 실행): https://claude.ai/code/routines
- 루틴 지시문 사본: [`docs/claude_routine_prompt.md`](docs/claude_routine_prompt.md)
- 추천 기록: GitHub Actions가 매일 `reports/YYYY-MM-DD.json`으로 저장소에 기록 (나중에 추천 성과 복기용)
- 루틴이 실패하거나 사용량 한도에 걸려도 07:00 숫자 리포트(GitHub Actions)는 그대로 옵니다
- Claude 클라우드 환경의 Environment variables 에 `STOCK_TELEGRAM_BOT_TOKEN`, `STOCK_TELEGRAM_CHAT_ID` 가 필요합니다
  (같은 환경의 다른 루틴이 쓰는 `TELEGRAM_*` 과 섞이지 않도록 `STOCK_` 접두어 사용)

### ⑧ API 방식 AI 코멘트 (선택, 현재 미사용)
`ANTHROPIC_API_KEY`가 있으면 Claude(기본 `claude-opus-5-5`)가 웹검색으로 각 추천 종목의 최근 2주 뉴스를 찾아
"병목·해자가 유지/강화/약화 되었는지", "기술적 셋업과 뉴스가 일치하는지"를 출처 링크와 함께 정리합니다.
안전 분류기가 요청을 거절할 경우 서버가 자동으로 대체 모델로 다시 시도하도록 `fallbacks: "default"`를 켜 두었습니다.

## 2. 설정 방법 (처음 한 번, 약 10분)

### Step 1. 텔레그램 봇 만들기
1. 텔레그램에서 **@BotFather** 검색 → 대화 시작
2. `/newbot` 입력 → 봇 이름과 아이디(끝이 `bot`) 입력
3. 받은 **토큰**(`123456789:ABC...` 형태)을 복사해 둡니다

### Step 2. 내 chat id 확인
1. 방금 만든 봇과 대화방을 열고 아무 메시지나 보냅니다 (예: `안녕`)
2. 브라우저에서 아래 주소를 엽니다 (`<토큰>` 부분을 바꿔서)
   `https://api.telegram.org/bot<토큰>/getUpdates`
3. 결과에서 `"chat":{"id":123456789` 의 숫자가 chat id입니다

   (로컬 파이썬이 있으면 `STOCK_TELEGRAM_BOT_TOKEN=<토큰> python -m stock_agent.telegram --get-chat-id` 로도 확인 가능)

### Step 3. GitHub Secrets 등록
저장소 → **Settings → Secrets and variables → Actions → New repository secret**

| 이름 | 값 | 필수 |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Step 1의 토큰 | 필수 |
| `TELEGRAM_CHAT_ID` | Step 2의 숫자 | 필수 |
| `ANTHROPIC_API_KEY` | https://console.anthropic.com 에서 발급 | 선택 (없으면 API 방식 AI 코멘트만 빠짐) |

GitHub Secret 이름은 `TELEGRAM_*` 그대로 두고, 워크플로가 프로그램에 `STOCK_TELEGRAM_*` 이름으로 넘겨 줍니다.

### Step 4. 수동 실행으로 테스트
저장소 → **Actions → Daily AI-Agent Stock Report → Run workflow**
1~3분 뒤 텔레그램으로 리포트가 오면 완료입니다.

### Step 5. 스케줄 확인
- 스케줄 실행은 **저장소의 기본 브랜치(default branch)에 있는 워크플로만** 동작합니다.
  다른 브랜치에서 작업했다면 기본 브랜치로 합쳐(merge) 주세요.
- 실행 시각: 월~토 06:50 KST 시작 → 보통 07시 전후 도착.
  GitHub 스케줄은 혼잡할 때 수십 분 늦어질 수 있습니다 (GitHub 측 제약).
- 공개(public) 저장소는 60일간 커밋이 없으면 GitHub가 스케줄을 자동 중지합니다. 그때는 Actions 탭에서 다시 켜면 됩니다.

## 3. 비용
- GitHub Actions: 공개 저장소 무료, 비공개 저장소도 무료 한도(월 2,000분) 안에서 충분 (1회 약 2~3분)
- 야후 파이낸스·텔레그램: 무료
- Claude 코멘트 루틴: API 요금 없음, 구독 사용량에서 차감 (1회 사용량은 실제 실행 후 확인 필요)
- Claude API(선택, 현재 미사용): 1회에 웹검색 최대 8번 + 토큰 비용. **추정치로 하루 약 $0.2~0.5**
  (검색 결과 길이에 따라 달라지며 실제 금액은 Anthropic 콘솔에서 확인 필요).
  줄이려면 `config.yaml`의 `ai.max_searches`를 낮추거나 `ai.effort`를 `low`로 바꾸세요.

## 4. 커스터마이즈 (`config.yaml`)
- 종목 추가: `universe`에 항목 추가 (코스피 `종목코드.KS`, 코스닥 `종목코드.KQ`)
- 추천 개수: `settings.top_n`
- 1회 위험: `settings.risk_per_trade_pct` (기본 1%)
- 피라미딩 비율: `settings.pyramid_split` (기본 50/30/20)
- 손절 폭: `settings.min_stop_atr`, `settings.max_stop_atr`
- 실행 요일·시각: `.github/workflows/daily-report.yml`의 `cron` (UTC 기준, KST−9시간)
  - 예: 매일 실행 → `"50 21 * * *"`

## 5. 한계와 주의 (꼭 읽어 주세요)
- **과거 성과 검증(백테스트)을 하지 않은 규칙입니다.** 규칙 자체는 널리 쓰이는 추세추종 방식(미너비니·오닐 계열)을 따랐지만,
  이 조합의 승률이나 기대수익은 확인되지 않았습니다.
- 유니버스가 30종목이라 **RS(상대강도)는 시장 전체가 아니라 이 30종목 안에서의 순위**입니다.
- 야후 파이낸스는 비공식 데이터 소스입니다. 지연·누락·오류가 있을 수 있고, 재무지표(매출성장률·PER)는 특히 부정확할 때가 있습니다.
- 매수 신호는 **전일 종가 기준**입니다. 장 시작 갭(시가가 크게 뛰거나 빠짐)이 생기면 진입가·손절가를 다시 판단해야 합니다.
- AI 코멘트는 틀릴 수 있습니다. 출처 링크로 원문을 확인하세요.
- 이 리포트는 투자 권유가 아니며 최종 판단과 책임은 본인에게 있습니다.

## 6. 로컬에서 실행
```bash
pip install -r requirements.txt
python -m stock_agent --dry-run --no-ai   # 텔레그램 발송 없이 화면 출력
python -m stock_agent --dry-run --no-ai --json picks.json   # 추천 결과 JSON 저장
python -m stock_agent.telegram --send-file note.txt --title "제목"   # 텍스트 파일 발송
python -m pytest -q                       # 테스트
```
